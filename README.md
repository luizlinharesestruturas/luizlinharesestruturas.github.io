## ⚙️ Como rodar localmente

Você pode testar o site localmente de forma muito simples usando **apenas o Python** (sem precisar instalar nada extra).

### 1. Abra o terminal na pasta do projeto

Exemplo:

```bash
cd luizlinharesestruturas.github.io
```

### 2. Inicie um servidor local

Com o **Python** instalado:

```bash
python -m http.server
```

Por padrão, o servidor será iniciado em:

```
http://localhost:8000/
```

### 3. Acesse no navegador

Abra o endereço acima no seu navegador para visualizar o site localmente.
